目标读者：想搞懂具身智能（Embodied AI）全栈——硬件、数据、策略、仿真、部署——并动手搭一套自己系统的工程师。

闭环环节 数据 / 策略（学习产物） 环境（真机或仿真）
图 0：具身智能是一个「感知 → 决策 → 执行 → 环境反馈」的闭环；数据从闭环中录得，学习把数据变回策略权重，再部署回闭环。全书按这条主线展开。

学习路径

STEP 1

具身智能全景

VLA 范式 vs 传统机器人学；七个开源仓库（基础设施 IsaacLab/lerobot → 核心模型 OpenVLA/openpi/GR00T → 组件 prismatic/unifolm-vla）各管哪一段；一个抓取任务的完整生命周期。
STEP 2

硬件抽象层

lerobot 的 Robot / MotorsBus / Camera 三大基类：从 SO-101 到人形机器人，接口怎么把硬件差异挡在下面。
STEP 3

遥操作与数据采集

leader-follower 遥操作；lerobot-record 的完整数据流（processor 链 → dataset 落盘）；标定与安全设计。
STEP 4

LeRobotDataset v3.0

机器人数据的标准格式：meta / parquet / mp4 目录结构、chunk 分片、stats 归一化、push_to_hub——具身智能的「ImageNet 底座」。
STEP 5

策略动物园

PreTrainedPolicy 接口与 action chunking；ACT 的 CVAE encoder-decoder、Diffusion Policy、时序集成——模仿学习的主要策略族。
STEP 6

VLA 与 Flow Matching

SmolVLA 全拆解：VLM 主干 + 小动作专家、flow matching 训练目标、噪声→动作的去噪循环——当今 VLA 的标准架构。
STEP 7

VLA 前沿

π0 的双流 PaliGemma + action expert；UnifoLM-VLA-0 与 GR00T N1.7 的 DiT 动作头（解耦 vs 原厂）；OpenVLA 与 Prismatic 双塔 backbone——模型侧的演进谱系。
STEP 8

仿真：Isaac Lab 架构

GPU 并行仿真为什么快；SimulationContext / Scene / Spawner；29 种机器人资产；Actuator 模型与传感器栈。
STEP 9

Manager-Based 环境

把 MDP 写成配置：八大 Manager 分工；ManagerBasedRLEnv.step() 的八步流程；以 LiftCube 任务为范本逐 cfg 拆解。
STEP 10

RL 训练闭环

奖励项怎么设计（权重为什么是 15 vs 1）；域随机化与课程学习；isaaclab train 入口与 RSL-RL 的 OnPolicyRunner。
STEP 11

Sim2Real 与部署

现实差距从哪来、靠什么抹平；lerobot 的部署形态：lerobot-rollout、gRPC 异步推理（policy server / robot client）、must-go 直通与队列聚合。
ROADMAP

实战：跑通自己的项目

六个里程碑：搭硬件 → 标定 → 遥操作录数据 → 训策略 → 评估部署 → 仿真加练与 VLA 微调。每步命令与陷阱清单。
