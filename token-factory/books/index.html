Token 工厂

如何把一组 GPU，建设成一座高吞吐、低延迟、高利用率、可调度、可计量、可盈利的 Token 工厂。一本面向推理工程师、AI 平台工程师和基础设施建设者的工程实践书。

"Token 工厂"是本书提出的系统工程抽象，不是某个开源项目的名字。全书数据来自作者自己的集群压测，示意数字均标注量级与出处，实测值以随书实验为准。
