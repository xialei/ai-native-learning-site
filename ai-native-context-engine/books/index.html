AI Native Context Engine

把企业数据变成 Agent 能理解、可推理、可执行、可审计的上下文。一本面向平台工程师、AI 应用工程师和系统架构师的设计书。

Context Engine 的目标不是替代模型或数据平台，而是把企业数据转换为可理解、可推理、可执行且可审计的上下文。
