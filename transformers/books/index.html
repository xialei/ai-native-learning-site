深入浅出 Transformers：权重以里的全部

「State-of-the-art pretrained models for inference and training.」

Transformers 是 HuggingFace 的模型库——几百个模型的公共代码，从分词到生成到训练的一条完整流水线。 这本书把它拆开，回答三个问题：transformer 怎么把整个互联网「记住」的？怎么支持 agent 调用工具的？解决问题的能力从哪来？

本站聚焦 huggingface/transformers 仓库(v5) trunk 823a6ea6d8 (5.21.0.dev0) · 所有章节源码锚定，行号随版本演进可能偏移

目标读者：想知道「模型为什么这样输出」的工程师——不停在 API 用法，直接读源码。
浏览方式：双击 transformers/books/index.html，或用浏览器打开；可对照 huggingface/transformers 仓库逐节阅读。

三个问题，十四章

这本书不是 API 手册，是围绕三个问题的源码解剖。每一章都把答案落在具体文件与行号上，并标清「库内能做什么、库外（其他书）管什么」的边界。

问题一

怎么「记住」整个互联网

模型参数就是一份超大的键值记忆体：注意力按 key 检索，FFN 是两层矩阵的「读出」；预训练把语料压进这几 GB 权重。→ 第 2-4 章
问题二

怎么支持 Agent 调工具

工具说明书织进 prompt(schema)、生成时停止条件截住、解析回结构化参数——模型侧五环全在库内，循环在库外。→ 第 8-9 章
问题三

解决问题的能力从哪来

能力是训练灌进权重的：Trainer 把「工具调用、指令跟随、解题模式」写成参数；推理侧的解码策略把能力表达出来。→ 第 5-7、11 章

学习路径

STEP 0

概述：三个问题

为什么读这个库、库内库外的边界、全书结构——先拿到地图再进森林。
STEP 1

仓库架构

目录结构、import 机制、PreTrainedModel 基类——531 个模型怎么共享一套骨架。
STEP 2

分词

文本变 token 的入口：词表、编码、特殊 token。一切输入的起点。
STEP 3

权重里的记忆

★ 重点。注意力怎么「检索」、FFN 怎么当键值存储——「记住互联网」的机制层。
STEP 4

KV Cache

短时记忆的存放与预算：为什么生成第二个 token 之后越算越省、显存怎么被吃掉。
STEP 5

生成循环

★ 重点。generate 的完整骨架：停止条件、采样、投机解码——token 怎么一个一个出来。
STEP 6

选词与约束

logits 加工链：温度、top-p、重复惩罚、结构化约束——「能力的表达」层。
STEP 7

并发服务

单节点服务化：continuous batching、KV 预算、准入与饥饿——多人同时用一个模型。
STEP 8

对话模板

多轮对话怎么变成一个 prompt：控制符、角色区段、工具说明书织入。
STEP 9

工具调用

★ 重点。从 schema 到解析回参的五环链——「模型侧」的全部，以及与 Agent 循环的分界。
STEP 10

多模态

图片、音频怎么变成 token 进同一个主干——输入统一化。
STEP 11

训练

★ 重点。Trainer 的训练步、loss 归一化、显存三板斧——能力是怎么被「教」进权重的。
STEP 12

量化与装载

v5 断代重做的装载系统：26 个量化后端、声明式权重变换、GGUF 不解压路线。
