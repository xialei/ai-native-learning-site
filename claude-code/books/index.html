✓ 它给你的，是可编排的原语

  • 工具 Tools：Bash、Read、Write、Edit、网络搜索——模型用函数调用驱动
  • 子代理 Subagents：独立上下文窗口的专职代理，主代理按需派遣
  • 技能 Skills：带指令与资源的渐进式能力包，按需载入不破缓存
  • Hooks、权限规则、提示记忆 CLAUDE.md、MCP 外接工具

这些原语能独立组合：一个工作流往往是「子代理跑探查 → 主代理改码 → Hook 拦截验证」的编排，而不是一个写死的功能。

✗ 它替你收的口（默认安全）

  • 默认要确认——写文件、跑命令先问你；可用权限规则放开或 --dangerously-skip-permissions 跳过
  • 沙箱 Bash——可把命令关进沙箱，限制网络与文件写
  • 企业策略——MDM 下发 managed-settings.json，强制禁用某些工具 / 市场
  • 不训练你的数据——反馈与使用数据有明确留存与访问限制

Claude Code 狂热地追求「能动手」，但同时把边界放在循环里而非事后补救：每一个工具调用都是一次可拦截、可审计的决策点。

学习路径

STEP 1

Claude Code 是什么

定位、能做什么不能做什么、与 Copilot / 普通 Chat 的本质区别：从「补全」到「执行」。
STEP 2

整体架构

内核、CLI/TUI、IDE、SDK、GitHub 集成各管什么；一次提示从哪里走到哪里，分层心智地图。
STEP 3

Agentic 循环

★ 重点。提示 → 模型 → 工具调用 → 结果回灌 → 再模型，这个循环怎么转、何时停、如何流式。
STEP 4

上下文构建

★ 重点。系统提示、CLAUDE.md 记忆、上下文压缩、工具结果裁剪——模型每轮到底看到什么。
STEP 5

内置工具

Bash、文件读写编辑、网络搜索与抓取；工具的输入输出如何成为模型可读的结构化结果。
STEP 6

权限模型

allow / ask / deny 三态、按工具与目录的规则、沙箱 Bash、企业托管策略与 MDM。
STEP 7

子代理与并行

Subagents 独立上下文窗口、按需派遣、并行编排；何时用子代理而非主代理一条道走到黑。
STEP 8

Hooks 生命周期

★ 重点。PreToolUse / PostToolUse / SessionStart / Stop 等钩子，stdin/stdout JSON 协议与退出码语义。
STEP 9

配置体系

settings 层级（企业 / 用户 / 项目 / 本地）、常用键、严格与宽松两套范例对照。
STEP 10

插件与 Skills

插件目录结构、市场、本仓库官方插件巡礼（code-review / feature-dev / hookify …）。
STEP 11

SDK 与程序化集成

把 Claude Code 当库：Claude Agent SDK 的查询 / 流式 / 工具与 MCP 注入，headless 自动化。
STEP 12

MCP 外接工具

Model Context Protocol：把数据库 / API / 内部系统接成工具与资源，扩展模型能触达的世界。

全书词表

高频术语速查；完整的命令/路径/配置键速查见第 14 章术语表。

术语含义详见
Agentic 循环（agentic loop）调模型 → 模型要工具 → 执行 → 结果回灌 → 再调模型的主循环，直到任务完成或触发终止条件。第 3 章
turn（轮）一次「调用模型 → 拿到回复」；一个 turn 里模型可以只说话，也可以带上若干 tool_use。第 3 章
tool_use / tool_result模型在回复里声明的「我要调某个工具」请求；系统执行后把结果包成 tool_result，作为新的 user 消息回灌。第 5 章
上下文（context）每次调模型前组装出的整段消息列表：系统提示、CLAUDE.md、对话历史、工具结果。第 4 章
CLAUDE.md随仓库走的「项目记忆」：构建上下文时自动注入的持久指令，团队约定写在这里。第 4 章
压缩（compaction）对话历史逼近窗口上限时，把旧消息摘要化腾出空间，循环得以继续。第 4 章
工具（tool）模型用函数调用驱动的动作：Bash、Read / Write / Edit、WebSearch / WebFetch 等内置能力。第 5 章
权限三态（allow / ask / deny）每个工具调用前的决策点：放行、先问用户、直接拒绝；可按工具与路径配规则。第 6 章
沙箱（sandbox）把 Bash 命令关进受限环境跑，限制网络访问与文件写入；只对 Bash 工具生效。第 6 章
子代理（subagent）拥有独立上下文窗口的专职 agent，主代理派遣任务，完成后只把结论回传。第 7 章
Hook挂在循环生命周期点（工具调用前后、会话起止等）的任意脚本：stdin 收 JSON，用 stdout 与退出码回话。第 8 章
settings 层级企业 / 用户 / 项目 / 本地四层配置，高层级优先且不可被低层级覆盖。第 9 章
插件（plugin）把命令、子代理、技能、Hooks、MCP 五种原语打包成一个可分享、可进市场的目录。第 10 章
Skill（技能）渐进式能力包：平时只留目录不进上下文，模型要用时再载入，不破坏提示缓存。第 10 章
SDK（Claude Agent SDK）把同一个 agentic 内核当库嵌进你的程序：发 prompt、消费流式事件、注入自定义工具。第 11 章
MCPModel Context Protocol：把数据库、内部 API、业务系统接成工具与资源，扩展模型能触达的世界。第 12 章
